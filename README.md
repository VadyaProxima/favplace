# Favplace

Рельеф вашего любимого места, отлитый в металле. Возьмите точку на карте —
и её настоящая топография превращается в 3D-рельеф (будущую вставку в кольцо).

> Текущий статус: в студии рендерится **перстень (signet)** — сужающаяся
> шинка расширяется к верху, и рельеф выбранной местности вырезан прямо в
> голове кольца, как единое литое изделие (`apps/web/src/lib/ringGeometry.ts`).

## Стек

| Слой | Технология |
|------|-----------|
| Frontend | Next.js 15, React 19, TypeScript, Tailwind v4 |
| Карта | MapLibre GL JS + Esri (basemaps + geocoding) |
| 3D | Three.js + React Three Fiber + Drei |
| DEM | AWS Terrain Tiles (Terrarium) |
| Backend | NestJS 11 + Prisma 5 + PostgreSQL 16 |
| Анимации | Motion (framer-motion) |
| Монорепо | pnpm + turborepo |

Карта идёт через **Esri** (World Imagery / Street / Hillshade — подложка
«Рельеф» использует World Hillshade, т.к. World Physical Map имеет тайлы
только до z8). Геокодинг: **Nominatim (OSM)** как основной поиск,
**Esri World Geocoder** как фолбэк. DEM-тайлы берутся с AWS S3 (Terrarium)
с ретраями и кэшем в памяти.

## Структура

```
favplace/
├── apps/
│   ├── web/              # Next.js фронтенд (:3000)
│   └── api/              # NestJS бэкенд (:4000)
├── packages/
│   ├── shared/           # Общие типы и контракты
│   └── terrain/          # Модуль генерации рельефа (DEM → heightmap → geometry)
```

## Быстрый старт

```bash
pnpm install
cp apps/api/.env.example apps/api/.env       # заполнить DATABASE_URL и токены

# локальная БД в контейнере (или свой postgres — тогда правьте DATABASE_URL)
docker run -d --name favplace-db -p 5432:5432 \
  -e POSTGRES_USER=favplace -e POSTGRES_PASSWORD=favplace \
  -e POSTGRES_DB=favplace postgres:16-alpine

pnpm --filter @favplace/api prisma:migrate   # накатить схему
pnpm dev                                     # запустить оба приложения
```

- Frontend: http://localhost:3000
- API: http://localhost:4000

Схема БД меняется только через миграции: правите `schema.prisma`, затем
`pnpm --filter @favplace/api prisma:migrate` — файл миграции коммитится
в репозиторий, и на сервере он же применяется автоматически при старте.

> Для рельефа и карты внешний доступ к `*.arcgisonline.com` и
> `s3.amazonaws.com/elevation-tiles-prod` должен быть открыт — иначе карта
> будет пустой, а `/api/terrain/heightmap` вернёт 500.

## API endpoints

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/api/terrain/heightmap?lat&lng&radius&resolution` | Heightmap по координатам (Terrarium DEM) |
| POST | `/api/orders/checkout` | Заявка из конструктора |
| POST | `/api/ai/identify-place` | AI-камера (OPENAI_API_KEY) |
| POST | `/api/admin/login` | Служебный вход (пароль → кука сессии) |
| POST | `/api/admin/logout` | Выход |
| GET | `/api/admin/session` | Активна ли сессия админа |

Регистрации покупателей нет: заказ оформляется без неё. Прежние
`/api/auth/*`, `/api/projects/*` и `/api/export/stl` фронт не вызывал —
модули удалены вместе с моделями `User`/`Project`.

## Служебный доступ

Страница `/admin` — форма с одним паролем. После входа в конструкторе
появляется кнопка «Скачать STL», обычным посетителям она не показывается.

```
ADMIN_PASSWORD=...     # пароль, знаете только вы
SESSION_SECRET=...     # ключ подписи куки; смена ключа разлогинивает
```

Без обеих переменных вход недоступен вовсе — пустой пароль не подойдёт.
Пароль сравнивается по HMAC за постоянное время, кука `favplace_admin`
подписана HMAC-SHA256, живёт 30 дней и помечена `httpOnly`/`SameSite=Lax`
(`Secure` — в проде). После 10 неверных попыток вход блокируется на 5 минут
по IP; блокировка задевает и правильный пароль, так что не увлекайтесь.

> **Это UX-гейт, а не защита модели.** Сборка STL целиком клиентская
> (`lib/stlExport.ts`), геометрия колец едет в браузер каждому посетителю,
> а болванки лежат открыто в `/models/*.glb`. Кнопка убирает файл из виду
> у покупателей, но человек с devtools соберёт STL и без неё. Полноценно
> закрыть модель можно только отказавшись от 3D-превью либо перенеся
> генерацию на сервер — а серверный экспорт уже удалялся ровно потому,
> что расходился с превью.

## Конструктор

`/create` — шесть шагов, слева 3D-превью, справа панель текущего шага,
внизу кликабельная лента прогресса.

1. **Форма** — 8 вариантов посадки рельефа, у каждого цена «от».
2. **Место** — поиск (Nominatim → Esri), пресеты, карта с подложками
   (Спутник / Схема / Рельеф). Белый фрейм-прицел закреплён в центре карты:
   двигайте карту под ним — что оказалось внутри рамки, то и анализируется.
   Размер рамки на экране гео-точный (равен площади анализа при текущем
   зуме): углами можно плавно менять площадь 100 м – 20 км, пресеты
   (100 м – 10 км) подгоняют зум под рамку, клик по карте центрирует её на
   точке. Рельеф строится по кнопке **«Анализировать»** (не в реальном
   времени — для производительности).
3. **Рельеф** — высота, детализация, гравировка внутри шинки (до 30 символов).
4. **Металл** — золото / серебро / платина, полированная / матовая,
   двухцветная отделка.
5. **Размер** — внутренний диаметр 15–23 мм с шагом 0,5 либо расчёт по
   замеренной длине окружности пальца.
6. **Заказ** — сводка, разбивка цены, форма заявки (имя, телефон, email,
   пункт выдачи СДЭК, комментарий, промокод).

Вся конфигурация живёт в query-строке, поэтому конструктор пересылается
ссылкой («Поделиться»), а открытая ссылка сразу строит рельеф по своему месту.

### Цены

Единая таблица — `packages/shared/src/pricing.ts` (`calcPrice`), её же
использует бэкенд: присланной с клиента сумме сервер не верит.

> Значения `RING_FORM_BASE_PRICE` / `MATERIAL_PRICE_FACTOR` предварительные —
> их нужно свести с реальной себестоимостью литья до запуска приёма заказов.

### Экспорт STL

Кнопка «Скачать STL» в конструкторе. Файл собирается **из живого меша сцены**
(`lib/exportTarget.ts` → `lib/stlExport.ts`), а не строится заново — так превью
и файл не могут разойтись.

Масштаб: единицы сцены переводятся в миллиметры по фактическому диаметру
посадочного отверстия. Отверстие измеряется подгонкой окружности методом Каса —
у процедурных форм `innerRadius = 1`, а GLB-модели нормируются по габариту, так
что единого коэффициента нет.

Перед скачиванием файл проверяется (`lib/meshAudit.ts`): замкнутость, наличие
немногообразных рёбер, минимальная толщина металла лучевым прозвоном через
`three-mesh-bvh`. Порог стенки — `MIN_CASTABLE_WALL_MM = 0.6`.

> Прежний серверный `POST /api/export/stl` удалён: он не вызывался с фронта и
> генерировал тор со смещением по heightmap, никак не связанный с восемью
> формами конструктора.

**Состояние форм по данным аудита (⌀17 мм, высота рельефа 2):**
>
> | Форма | Замкнутость | Мин. стенка | Готовность |
> |---|---|---|---|
> | Горный | да | 0,84 мм | к литью готов |
> | Диск | 720 граничных рёбер | 0,12 мм | нужна доработка |
> | Цилиндр | 720 граничных рёбер | 0,12 мм | нужна доработка |
> | Планка | 12 475 немногообразных рёбер | 0,02 мм | нужна доработка |
>
> Составные формы склеиваются через `mergeGeometries` из двух отдельных
> оболочек — отсюда дырки и самопересечения. Нужен настоящий булев union.

### Заявки

`POST /api/orders/checkout` — без авторизации. Заявка пишется в `Order`
(`userId`/`projectId` = null, снапшот конфигурации в `configJson`) и уходит
уведомлением в Telegram, если в `apps/api/.env` заданы:

```
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHAT_ID=...
```

Без этих переменных заявка просто пишется в лог API. Оплата не подключена:
статус заказа — `pending`, менеджер связывается с клиентом.

## AI-камера (опционально)

Эндпоинт `/api/ai/identify-place` требует ключ. Создайте `apps/api/.env`:

```
OPENAI_API_KEY=sk-...
TELEGRAM_BOT_TOKEN=      # опционально — уведомления о заявках
TELEGRAM_CHAT_ID=
```

## Деплой

Один VPS (2 vCPU / 2–4 ГБ, Timeweb Cloud или Beget) — весь стенд описан
в `docker-compose.yml`: PostgreSQL, API, Next и Caddy. Наружу открыт только
Caddy, он же сам выпускает и продлевает HTTPS-сертификат.

```bash
# на сервере: docker + docker compose plugin
git clone <репозиторий> favplace && cd favplace
cp .env.example .env        # SITE_DOMAIN, POSTGRES_PASSWORD
docker compose up -d --build
```

Домен из `SITE_DOMAIN` должен A-записью указывать на IP сервера, порты 80
и 443 — открыты, иначе Let's Encrypt не выдаст сертификат.

Миграции накатываются автоматически: `apps/api/docker-entrypoint.sh`
выполняет `prisma migrate deploy` перед стартом API.

Обновление:

```bash
git pull && docker compose up -d --build
```

Бэкап БД (том `pgdata` переживает пересборку образов, но не удаление тома):

```bash
docker compose exec -T db pg_dump -U favplace favplace | gzip > backup-$(date +%F).sql.gz
```

| Файл | Назначение |
|------|-----------|
| `docker-compose.yml` | Состав стенда и переменные окружения |
| `Caddyfile` | HTTPS, маршрутизация `/api/*` в NestJS, остальное в Next |
| `apps/api/Dockerfile` | Образ API: сборка монорепо, prune dev-зависимостей |
| `apps/web/Dockerfile` | Образ фронта: Next standalone |
| `.env.example` | Шаблон переменных для compose |
