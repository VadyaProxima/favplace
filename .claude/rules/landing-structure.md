# Landing Page Structure

Standard single-page layout following conversion funnel logic.

**Required:** Header, Footer
**Optional:** all other sections — chosen based on the task

---

## Required

### Header
Site header with the product logo and anchor navigation menu.

### Footer
Footer with additional links and copyright.

---

## Optional

### Hero Section
Main screen with the primary headline, subheadline, and CTA button.

### Problem Section
Description of the target audience's pain points.

### Solution Section
Presenting the product as a solution, highlighting key advantages.

### Benefits Section
Visual list of benefits with icons.

### How It Works Section
Simple step-by-step instructions in 3–4 steps.

### Testimonial Section
User reviews to build trust.

### FAQ Section
Answers to frequently asked questions.

### CTA Section
Block with a call to action (registration, purchase, subscription).

---

| Block | Purpose | Required |
|-------|---------|----------|

| Benefits | Advantages with icons | no |
